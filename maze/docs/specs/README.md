Recommended reading order:

1. Start with [SCENARIO_SUITE_INDEX.md](./SCENARIO_SUITE_INDEX.md)
   to avoid mixing the large map, the legacy mini suite, and the new didactic suite.
2. Read the scenario-specific spec you need:
   - large reference map
   - legacy mini suite
   - didactic tutor suite
3. Then read the implementation plan and experiment notes.

Rules:

- A spec describes intended design and experimental use, not only the current implementation.
- Scenario suite names should be used consistently in reports.
- Do not mix `MiniRiskyMazeSuite_v0` and `TutorDidacticMazeSuite_v1`
  unless the report explicitly says so.
