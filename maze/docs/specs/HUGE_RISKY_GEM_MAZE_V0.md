## 概况

- size: `61 x 39`
- coordinate: zero-indexed `(x, y)`, origin at top-left
- passable cells: `1367`
- doors: `5`
- keys: `4`
- gems: `7`
- exits: `2`
- danger types: `3`
- safe floor types: `3`

## Legend

- `#`: wall / blocked
- `.`: safe_floor_type_0
- `,`: safe_floor_type_1
- `:`: safe_floor_type_2
- `r`: danger_type_1_spike_ridge
- `m`: danger_type_2_toxic_mist
- `q`: danger_type_3_quicksand
- `K`: key / useful object
- `D`: locked door / bottleneck
- `g`: gem / subgoal
- `E`: exit

- `SPEC["tasks"]["teach"]`

程序化校验已经覆盖：

- `time_limit` 是否高于 walkable shortest-path lower bound
